# Resources

## Dataset

- **FIRE Dataset** (NASA Space Apps Challenge), Kaggle: <https://www.kaggle.com/datasets/phylake1337/fire-dataset>
- 999 images: 755 fire, 244 no-fire. Downloaded automatically by the notebook through `kagglehub`; not stored in this repository.

2. He et al., "Deep Residual Learning for Image Recognition," CVPR 2016 — <https://arxiv.org/abs/1512.03385>
3. Sandler et al., "MobileNetV2," CVPR 2018 — <https://arxiv.org/abs/1801.04381>
4. Hu et al., "Squeeze-and-Excitation Networks," CVPR 2018 — <https://arxiv.org/abs/1709.01507>
5. Lin et al., "Focal Loss for Dense Object Detection," ICCV 2017 — <https://arxiv.org/abs/1708.02002>
6. Lilhore et al., "Real time fire and smoke detection using vision transformers and spatiotemporal learning," Scientific Reports 2026 — <https://doi.org/10.1038/s41598-026-36687-9>
